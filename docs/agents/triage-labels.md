# Triage Labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must assess the issue |
| `needs-info` | `needs-info` | The issue needs more information |
| `ready-for-agent` | `ready-for-agent` | An agent can do the specified work |
| `ready-for-human` | `ready-for-human` | A person must do the work |
| `wontfix` | `wontfix` | The project will not fix the issue |

Use the tracker label that matches the required role.
