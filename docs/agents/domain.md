# Domain Docs

This repo uses one domain context.

## Before Code Work

Read `CONTEXT.md` if it exists.

Read relevant records in `docs/adr/` if they exist.

Do not report missing domain files. Domain modeling creates them only when needed.

## Language

Use the terms from `CONTEXT.md`.

Do not use an avoided term for a defined concept.

If a required term is missing, use domain modeling to define it.

## Decision Conflicts

State when proposed work conflicts with an existing decision record.

Do not replace that decision without user approval.
